# ACP historical design archive

Status: **Historical decision-record index**

This directory preserves architecture proposals, review packages, milestone reports, execution prompts, handoffs, and dated integration inspections. These records explain how ACP reached its current design; they are not the current specification.

Use [the documentation index](../docs/README.md) for current normative and integration guidance. In particular:

- Current security semantics: [docs/SECURITY.md](../docs/SECURITY.md)
- Current implementation status: [docs/IMPLEMENTATION_STATUS.md](../docs/IMPLEMENTATION_STATUS.md)
- Current Prism/Remote integration: [docs/integration](../docs/integration/)
- Current credential architecture: [docs/security/CREDENTIAL_ISSUER_ARCHITECTURE.md](../docs/security/CREDENTIAL_ISSUER_ARCHITECTURE.md)

Historical documents retain their original assertions, completion claims, and blockers. A historical PASS applies only to the revision and environment named in that record. “Codex prompt,” “AFK handoff,” “plan,” and “completion report” documents are execution history and never override schemas, normative documents, or current source.
